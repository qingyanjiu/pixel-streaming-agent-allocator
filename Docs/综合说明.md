# 综合说明

系统由中央调度、Worker 本机管理和播放器 Gateway 组成：

```text
客户端
  -> Allocator
  -> Gateway
  -> 本机 Wilbur
  -> UE

Allocator
  -> Worker Agent
  -> Slot
```

部署目录：

```text
项目根目录\
├── Allocator\
├── Worker\
├── Gateway\
├── Docs\
└── WebServers\
```

## 配置分工

Allocator 管理所有 Worker 地址：

```text
Allocator\config\workers.json
```

Allocator 自身策略和 Client API Key：

```text
Allocator\allocator.json
```

Gateway Token 通过 `allocator.json` 的 `gatewayTokenFile` 配置。

Worker 本机路径、端口、Token 和 Slot：

```text
Worker\worker*.json
```

Gateway 本机播放器入口：

```text
Gateway\gateway.json
```

Worker 共享运行环境：

```text
WebServers\
```

## 部署原则

- Allocator 机器不需要 Worker 源码或 WebServers。
- Worker 机器不需要 Allocator 源码。
- Gateway 与 Worker、Windows 构建和 WebServers 同机部署。
- Gateway 通过 Allocator 校验 Ticket，并把流量代理到本机 Wilbur。
- Worker 必须能访问固定路径的 WebServers 和游戏构建。
- 所有 Worker 的 `9101` 必须能被 Allocator 访问。
- 客户端访问 Gateway `9300`，不直接访问远端 `801/802`。
- 客户端仍直接连接 WebRTC UDP 或 TURN。
